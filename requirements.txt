# cells). Resolves directly to the final pinned versions, so torch 2.4.0 and the
# bleeding-edge git diffusers are never installed and thrown away.

# Usage (Colab):
#   %cd /content
#   !git clone https://github.com/Zheng-Chong/CatVTON.git
#   !pip uninstall -y torch torchvision torchaudio xformers torchao
#   !pip install -r requirements.txt
#   # >>> then RESTART the runtime once before continuing <<<
#
# Why the clone + uninstall + restart are still separate (a requirements file can't do them):
#   * git clone  : the notebook imports model.cloth_masker / model.pipeline from the repo.
#   * uninstall  : clears Colab's PREINSTALLED CUDA-variant torch (avoids the +cu121 vs
#                  +cu124 "looks satisfied, skipped" trap) and removes torchao, whose
#                  transformers integration crashes on torch 2.5 with `torch.int1`.

#                   transformers to 4.44.2 + the second torchao uninstall unnecessary.)
#   * restart    : swapping the core torch build requires a fresh Python process.
